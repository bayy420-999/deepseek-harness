# Agent Note：移动端覆盖层布局模式——720px 以下用抽屉替代被挤压的栏位

Status: implemented

[English](2026-08-20-mobile-overlay-layout-mode.md) | 中文

## 问题

AppFrame 的让步链（packages/client/ui-layout）以桌面端为先：中心栏下限为 640px，详情栏渲染宽度不低于 300px，侧边栏从不低于 264px。在手机宽度视口下，这条链使两个面板都不可用。低于约 940px 时打开详情栏会解析为零宽度（让步链第 3 步的自动关闭），于是「查看」操作在手机上静默失效。展开自动折叠的侧边栏会把中心栏挤压到 360px 屏幕上的约 80px——这是设计中「中心栏吸收挤压」的兜底方案，但实际无法使用。挂载链还使用 `height: 100%`，移动端浏览器会按大视口解析该值，因此可见的地址栏或工具栏会把输入框挡在折叠线以下。

## 决策

AppFrame 在低于 `MOBILE_OVERLAY_MAX`（720px，columns.ts）时切换为移动端覆盖层模式：

- 网格只保留折叠后的控制栏轨道（56px）和中心栏。打开的面板不再是网格轨道，因此中心栏不会向它们让渡宽度。
- 展开的侧边栏渲染为覆盖式抽屉：同一个 `.sidebarCol` 容器变为绝对定位，宽度取 `SIDEBAR_DRAWER_WIDTH`（320px，夹取到 `viewport - 64`，保证会话区边缘可触及），位于点按关闭的遮罩（`--dsw-alias-bg-mask-1`）之上。开关操作复用现有窄视口语义——`toggleSidebar` 翻转 store 的 `narrowExpanded` 覆盖位，因此没有新增 store 状态，也不会改写任何宽度偏好。
- 打开的详情栏渲染为整幅覆盖面板（`.detailsCol` 容器变为 `inset: 0` 的绝对定位），沿用面板自带的关闭按钮。
- 两个容器只换类名、不换挂载点，因此 slot 子树在姿态切换期间保持挂载；让步求解器仍基于仅含控制栏的网格运行（其输出不再用于覆盖层宽度）。
- 720px 以下不渲染拖动手柄；该宽度下不存在可拖拽调整的网格栏位。
- 两个覆盖层都位于 z-index 12（遮罩为 11），低于外壳覆盖层（20）与门架菜单（100+）；两者同时打开时详情覆盖层盖住抽屉。
- 跨断点切换不需要任何迁移：宽度偏好从未被改动，重新变宽即可恢复常规栏位（仍处于打开状态的抽屉变回展开的窄视口栏位，行为同前）。

同一变更还把外壳挂载链（`packages/client/web/src/base.css`）从 `height: 100%` 改为受支持时的 `height: 100dvh`（在桌面端为惰性值，dvh 等于普通视口高度），并使 ui-conversation 在 720px 及以下收紧头部边距（左右 12/16px）并将面包屑上限改为 140px。

## 备选方案

**在 `SIDEBAR_AUTO_COLLAPSE`（1024px）处设置单一覆盖层断点。** 否决：竖屏平板确实放得下控制栏加可用宽度的中心栏，且控制栏让工作区列表无需手势即可触达；720px 使一切宽于手机尺寸的视口保持桌面端行为。

**全视口宽度抽屉。** 否决：会把会话区完全挡在抽屉后面；留出 64px 让会话区边缘既作为关闭提示也作为点按目标，与遮罩一致。

**为移动端姿态新增 store 标志。** 否决：`narrowExpanded` 已经编码了「用户在窄视口下重新展开侧边栏」，抽屉正是该姿态的不同渲染方式；增加平行状态会为一个开关制造两个事实来源。

**详情栏采用底部抽屉或右侧抽屉。** 否决：详情面板的主要载荷是终端输出与 JSON，需要完整宽度；`inset: 0` 直接复用面板自带的关闭按钮，无需新增控件。

**保留挤压中心栏的行为。** 否决：它是原状，而其在手机上产生的 80px 中心栏正是本说明要移除的缺陷。

## 后果

720px 以下的渲染宽度不再是存储偏好的纯函数（抽屉与覆盖层宽度是派生值），但存储偏好保持纯粹且不被触碰，因此让步链的无迟滞契约在断点之上依然成立。ui-layout 之外没有任何代码读取覆盖层容器；侧边栏 owner share 保持 `collapsed`/`width` 契约，在移动端打开时 `width` 即抽屉宽度。详情 slot 子树关闭时仍以零宽度保持挂载，与之前完全一致。ui-layout 的 README 双语文档已记录该模式。

## 测试

`packages/client/ui-layout/tests/app-frame.client.spec.tsx` 新增「AppFrame — mobile overlay mode」用例块（8 例）：仅控制栏轨道的挂载、打开抽屉不改变轨道（owner props 为抽屉宽度）、360px 视口下的抽屉宽度夹取、点按遮罩关闭、详情以覆盖层渲染且框架属性缺省、closeDetails 移除覆盖层，以及两种断点退出（抽屉打开与详情打开）在 slot 子树保持挂载的情况下恢复栏位姿态。布局可见变更的组合式浏览器检查仍为 CI 中的 `DSH_SNAPSHOT=replay pnpm run test:web`；该检查无法在 Android/Termux 开发主机上运行，因为 Playwright 未为该平台提供浏览器构建。
